# Hardware assumptions

> Marked items are **machine-specific**. Change them when moving to another PC/laptop.

## CPU / memory

| Item | Value | Machine-specific? |
|---|---|---|
| CPU | 12th Gen Intel Core i5-1245U (Alder Lake-P) | Yes |
| RAM | 16 GiB | Yes |
| Scaling governor observed | `powersave` via `intel_pstate` | Soft |

## GPU

| Item | Value | Machine-specific? |
|---|---|---|
| GPU | Intel Alder Lake-UP3 GT2 Iris Xe (`8086:46a8`) | Yes |
| Kernel driver | `i915` (module `xe` also present, unused for this session) | Soft |
| Mesa | 26.x series on capture host | Soft |
| DRM node | `/dev/dri/card1`, `renderD128` | Soft |

Intel Gen12 texture size limit relevant to the Quickshell bug: **16384** px on one dimension.

## Paths that contain a home directory

These appear in `illogical-impulse/config.json` and must be edited after clone:

| Setting | Example on capture host |
|---|---|
| `background.wallpaperPath` | `/home/<user>/Downloads/new.jpg` |
| `screenRecord.savePath` | `/home/<user>/Videos` |

Wallpaper image itself is **not** in this repository.
